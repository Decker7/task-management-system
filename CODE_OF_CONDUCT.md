# Code of Conduct

## Our pledge

We want this project to be a respectful and welcoming place for contributors.
Everyone who participates is expected to be considerate, constructive, and
professional.

## Expected behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and experience levels.
- Give and receive feedback gracefully.
- Focus criticism on ideas and code, not people.

## Unacceptable behavior

- Harassment, intimidation, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeated disruption of project discussions.

## Enforcement

Project maintainers may remove comments, close issues, or block contributors
who do not follow this code of conduct. Concerns can be reported through the
security contact process in `SECURITY.md` if they should not be public.
